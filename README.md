# Автопостинг рилсов

Автомонтаж и автопубликация коротких видео: YouTube Shorts, Instagram Reels, TikTok, VK.

- `reels-autopost/skills/reels-autopost-setup/` — мастер настройки (первый запуск)
- `reels-autopost/skills/reels-publisher/` — публикация рилсов через Upload-Post API
- Секреты (`UPLOAD_POST_API_KEY`) хранятся в `.env`, который не попадает в git
